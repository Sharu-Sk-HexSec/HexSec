HexSec for Windows x64.

Download HexSec-Windows-compact.zip, extract the complete folder, and open HexSec.exe.

The release includes the online/local player, artwork-colored blur, album-song collections, dark/light themes, optional lyrics, duplicate-aware Next and playback-history Previous controls. Music availability and compressed online audio quality depend on the source. Unlabelled remakes may not be detected. Google library sync has upstream limitations and requires your own OAuth setup. No private credentials are bundled.

HexSec-source.zip contains source code and build/test instructions. SHA256SUMS.txt contains the Windows ZIP checksum.
