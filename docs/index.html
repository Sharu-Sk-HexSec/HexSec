Connect YouTube Music

Sign in securely in your normal browser. HexSec never asks for your Google password.

One-time Google setup
  1. Create a personal project in Google Cloud and enable YouTube Data API v3.
  2. Configure Google Auth Platform branding and audience. If the app is in Testing, add your own Google account as a test user.
  3. Create an OAuth client with application type Desktop app, then download its client JSON.
  4. Import that JSON below, then click Connect Google.

The library adapter uses the YouTube OAuth permission, which Google may describe as managing your YouTube account. This app implements library reads only; it does not edit your YouTube library. Review Google's consent screen before allowing access.

Tokens and imported configuration are encrypted with Windows credential protection on this computer. Disconnect removes this app's local credentials and cached collection. Google permission can also be removed from your Google account.
