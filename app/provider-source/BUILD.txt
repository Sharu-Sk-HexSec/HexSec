HexSec adds aural-entry.ts for catalogue, quality and radio exports.
The suggestions use case skips upstream response metadata before parsing songs.

Rebuild provider.cjs from this directory with Node.js + npm:
  npm install --ignore-scripts
  npm install --no-save esbuild@0.28.2
  npx esbuild aural-entry.ts --bundle --platform=node --format=cjs --outfile=../provider.cjs

The Electron main process invokes Echo.request internally; no HTTP port is
opened by the music provider. The provider connects to JioSaavn upstream.
